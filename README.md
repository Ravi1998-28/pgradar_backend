# 🏠 PGradar - PG Listing Backend Server

PGradar is a backend API server built using **Express.js**, **MongoDB**, and **JWT Authentication**. It supports user registration, login, and PG listing management based on city.

## 🚀 Features

- User Registration & Login with role (`owner` / `manager`)
- JWT Authentication for secure APIs
- MongoDB database connection with Mongoose
- Scalable project structure (controllers, routes, models)
- Environment variables support using `.env`
